# Assets

Files used by the project README:

* `banner.svg` is the README header banner.
* `headings/` holds one colored SVG per section heading. Each SVG is transparent and uses the same teal palette so headings stay readable on light and dark themes.
* `crack.png` shows a crack run in a terminal.
* `help.png` shows the command overview printed by `descry`.
* `decode.png` shows a base64 decode session.

Keep the three screenshots at the same display width in the README.
